# SpendWise – Budget Management Application

## Project Description
SpendWise is a simple budget management application that helps users manage their money by entering their total budget and expenses. It calculates and displays the remaining balance using JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Implemented

### 1. Variables
Variables store the total budget, total expenses, and remaining balance.

### 2. Data Types
The application uses numbers to perform budgeting calculations.

### 3. User Input
The `prompt()` function collects the user's budget and expenses. The `Number()` function converts the input into numerical values.

### 4. Calculations
The application subtracts total expenses from the total budget to calculate the remaining balance.

### 5. Functions
The `calculateBalance()` function accepts budget and expenses as parameters and returns the remaining balance.

### 6. Console Output
The `console.log()` function displays the budget summary in the browser console.

## How to Run the Application
1. Download or clone the SpendWise repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter your total budget when prompted.
5. Enter your total expenses.
6. Open the browser developer tools and select Console to view the results.

## Project Structure
- `index.html` – Contains the HTML page structure.
- `style.css` – Contains the webpage styling.
- `script.js` – Contains JavaScript logic and calculations.
- `README.md` – Contains project documentation.
